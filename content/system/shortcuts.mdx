# Keyboard shortcuts

## Windows

Every one of these acts on the **front window** — the one on top of the stack.

| Shortcut | Does |
| --- | --- |
| `⌃⌥←` | Pin to the left half |
| `⌃⌥→` | Pin to the right half |
| `⌃⌥↑` | Expand to fill, or restore |
| `⌃⌥↓` | Minimize to the taskbar |
| `⌃⌥W` | Close |
| `⌃⌥Tab` | Cycle through open windows |
| `⌃⌥D` | Show the desktop — minimize everything |

Pinning to the side a window already holds lets it float free again.

## Everywhere

| Shortcut | Does |
| --- | --- |
| `⌘K` | Search everything, including the text inside these documents |
| `?` | Open this list |
| `Esc` | Close search |
