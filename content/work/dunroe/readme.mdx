# Dunroe.io

**Business Intelligence Analyst** · May 2021 – Aug 2021 · Calgary, AB

Dunroe sells social media analytics by vertical. Banks wanted to
know how their analytics performed against other banks, but it was only possible if
someone has already figured out which accounts belonged to which industry. 
My summer was spent building that dataset and then launching the go-to-market.

## Finding the accounts

I co-developed a **Python** web scraper using **BeautifulSoup** and Google's Search
REST API to resolve **5,000+** financial institutions and thousands of schools to
their **Instagram** handles, then categorized every profile by industry. That dataset
became a new product offering for **250+ clients**.

## Go-to-market

I kickstarted the company's first go-to-market, leading the **Google Ads** campaign:
defining the target audiences and keywords, then running **A/B tests** against
click-through and conversion rates tracked through **Google Analytics**. 
Traffic grew **20% in three months**.
